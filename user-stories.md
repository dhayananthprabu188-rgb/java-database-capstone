# User Stories

## Doctor
- As a doctor, I want to view my upcoming appointments, so that I can prepare for patient visits.
- As a doctor, I want to update patient records after a consultation, so that the history stays accurate.
- As a doctor, I want to set my available time slots, so that patients only book when I'm free.

## Patient
- As a patient, I want to book an appointment online, so that I don't have to call the clinic.
- As a patient, I want to view my medical history, so that I can track my treatment progress.
- As a patient, I want to cancel or reschedule an appointment, so that I have flexibility.

## Admin
- As an admin, I want to add or remove doctors from the system, so that the doctor list stays current.
- As an admin, I want to view all appointments across the clinic, so that I can manage scheduling conflicts.
- As an admin, I want to manage patient accounts, so that inactive users can be handled properly.
